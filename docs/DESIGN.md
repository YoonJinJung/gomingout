# 고밍아웃 디자인 가이드

UI 작업 전 반드시 이 문서를 따른다. 여기 없는 색상·글꼴·간격 값을 임의로 만들지 말 것. 필요하면 먼저 제안한다.

## 1. 콘셉트
**"밤에 조용히 털어놓는 곳."**
사람들이 고민을 가장 많이 꺼내는 시간은 밤이다. 어두운 남색 밤하늘 위에 부드러운 라벤더 빛이 떠 있는 느낌.
- 차분하고 조용하게. 자극적인 색, 큰 움직임, 과한 장식은 피한다.
- 오래 읽어도 눈이 편해야 한다(순수 검정 배경, 순수 흰 글자 금지).
- 따뜻하고 조심스러운 말투. 사용자를 재촉하거나 판단하지 않는다.

## 2. 테마
- **다크 모드가 기본.** 모든 화면은 다크 기준으로 먼저 설계한다.
- 라이트 모드는 토큰만 정의해두고, 설정의 테마 전환은 M7에서 추가한다.
- 색상은 반드시 CSS 변수(토큰)로만 사용. 컴포넌트에 hex 값 직접 사용 금지.
- Tailwind 설정과 shadcn/ui 테마 변수를 이 토큰에 연결한다.

## 4. 타이포그래피
- 글꼴: **Pretendard Variable** (한글), 폴백 `-apple-system, system-ui, sans-serif`
- 로고만 별도 글꼴 사용 가능(추후 결정)

| 이름 | 크기/줄간격 | 굵기 | 용도 |
|---|---|---|---|
| title-lg | 22/30 | 700 | 페이지 제목 |
| title | 18/26 | 600 | 게시글 상세 제목 |
| title-sm | 16/24 | 600 | 카드 제목 |
| body | 16/27 (1.7) | 400 | **게시글·댓글 본문 (긴 글 가독성 최우선)** |
| body-sm | 14/21 | 400 | 카드 미리보기, 보조 설명 |
| caption | 12/16 | 500 | 배지, 시간, 카운트 |

- 입력창 글자는 16px 이상 (iOS 확대 방지)
- 본문 문단 간격 넉넉히, 한 줄 최대 폭 약 680px

## 5. 간격·모서리·그림자
- 간격 단위 4px 배수: 4, 8, 12, 16, 20, 24, 32
- 화면 좌우 여백: 모바일 16px
- 모서리: 카드 16px, 버튼·입력 12px, 칩·배지 999px(완전 둥글게)
- 그림자는 거의 쓰지 않는다. 층 구분은 `--surface` 단계와 `--border`로.
- 떠 있는 요소(바텀시트, 모달)만 은은한 그림자 + 배경 딤 `rgba(5,6,15,0.6)`

## 6. 레이아웃
### 모바일 (기본, < 768px)
- 상단 앱바: 로고(좌), 페이지 제목 또는 카테고리명
- **하단 탭 5개: 홈 / 카테고리 / 글쓰기 / 쪽지 / 마이**
  - 글쓰기는 가운데(3번째) 강조된 라벤더 원형 버튼. 좌우 2개씩 균형을 맞춘다
  - 쪽지는 준비 중이다(D24). 아이콘 우상단에 `--text-subtle` 점 하나로만 표시하고,
    배지·뱃지 숫자 같은 자극적인 표현은 쓰지 않는다
- 하단 탭 영역은 safe-area 여백 반영, 아이콘이 상단 경계선에 붙지 않도록 위쪽 여백을 둔다

### 태블릿·데스크톱 (≥ 1024px)
- 가운데 본문 컬럼 최대 680px
- 좌측 사이드바: 로고, 메뉴(홈·카테고리·쪽지·마이), 글쓰기 버튼, 로그인
  - 준비 중 메뉴는 여유가 있으므로 "준비 중" 칩을 글자로 표시한다
- 하단 탭은 숨김

## 7. 핵심 컴포넌트
### 게시글 카드 (PostCard)
- 위: 카테고리 칩(소분류) · 작성 시간
- 제목(title-sm, 1줄 말줄임)
- 본문 미리보기(body-sm, 2줄 말줄임, `--text-muted`)
- 아래: 작성자 표시 · 공감 수 · 댓글 수 · 스크랩 수 (lucide 아이콘 + caption)
- 카드 전체 탭 영역, 눌림 시 `--surface-2`

### 작성자 표시 (AuthorLabel)
- 닉네임: `닉네임` + MBTI 배지(공개 시)
- 익명: `익명` 배지(`--anon-bg`/`--anon-text`) + MBTI 배지(표시 선택 시)
- 댓글 익명 번호: `익명3`, 글쓴이: `글쓴이` 배지(`--primary-soft` 배경, `--primary` 글자)
- MBTI 배지: 테두리형(outline) 칩, `--primary` 테두리, caption 크기

### 글쓰기 화면
- 카테고리 선택(대분류 → 소분류 바텀시트)
- 제목, 본문(자동 높이)
- 하단 옵션: **익명으로 쓰기 토글(기본 ON)**, MBTI 표시 토글(익명 ON일 때만 보임, 기본 ON)
- 등록 버튼: primary, 필수값 없으면 비활성

### 공감·스크랩 버튼
- 비활성: `--text-muted` 외곽선 아이콘
- 활성: 공감은 `--like` 채움, 스크랩은 `--primary` 채움
- 누를 때 아주 짧은 스케일 애니메이션(0.95 → 1, 150ms)만

### 위기 안내 박스 (CareBox)
- **경고색(빨강·노랑) 사용 금지.** `--care-bg` 배경, `--care` 좌측 강조선 또는 아이콘
- 문구 톤 예시: "지금 많이 지치셨다면, 혼자 견디지 않아도 괜찮아요. 언제든 이야기 들어줄 곳이 있어요."
- 상담 창구(109, 1577-0199, 1388)는 탭하면 전화 연결되는 버튼으로
- 작성 전 모달에서도 같은 스타일. "계속 작성하기" 버튼을 함께 제공(막지 않음)

### 빈 상태 · 로딩 · 에러
- 빈 상태: 작은 달·별 일러스트 + 부드러운 문구 ("아직 조용한 밤이에요. 첫 이야기를 들려주세요.")
- 로딩: 스켈레톤(`--surface-2`), 스피너 최소화
- 에러: 탓하지 않는 문구 + 다시 시도 버튼

## 8. 모티프
- 달·별은 **로고, 빈 상태, 스플래시에만** 제한적으로 사용
- 홈 상단에 아주 은은한 밤하늘 그라데이션(`--bg` → `#161338`) 허용. 그 외 그라데이션 금지

## 9. 아이콘
- lucide-react 사용, 선 두께 1.75, 기본 크기 20px
- 이모지를 아이콘 대신 쓰지 않는다

## 10. 움직임
- 전환은 150~200ms ease-out, 페이드·슬라이드 소량
- `prefers-reduced-motion` 시 애니메이션 제거

## 11. 접근성
- 텍스트 대비 WCAG AA 이상
- 포커스 링: 2px `--primary`, 오프셋 2px
- 터치 영역 최소 44×44px
- 아이콘 버튼에는 aria-label

## 12. 문구(Microcopy) 원칙
- 존댓말, 짧고 부드럽게
- 명령형보다 권유형 ("작성하세요" → "들려주세요")
- 에러·제재 안내도 사용자를 비난하지 않는 표현

## 13. PWA
- `theme_color`, `background_color`: `#0E1123`
- iOS status bar: `black-translucent`
- 앱 아이콘: 남색 배경 위 라벤더 초승달 (추후 제작)

## 14. 금지 사항
- 순수 검정(`#000`) 배경, 순수 흰색(`#FFF`) 본문 글자
- 위기 관련 UI에 빨강·경고 표현
- 토큰 외 임의 색상, 과한 그라데이션·그림자·네온 효과
- 본문 14px 미만
