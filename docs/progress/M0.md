# M0. 로컬 기반 세팅 완료 보고서

## 요약

pnpm 모노레포(web / api / shared)를 세우고 `pnpm dev` 한 번으로 web(3000)·api(4000)이 함께 뜨도록 했다.
Docker Postgres·Mailpit, Zod 환경변수 검증, `app.ts`/`server.ts` 분리, 에러 응답 규약, `EmailSender`·`RateLimiter`
인터페이스까지 배포 호환 구조로 깔았다. `docs/DESIGN.md`의 색상·타이포 토큰 전체를 Tailwind v4 `@theme`와
shadcn 변수에 연결하고 Pretendard를 self-host했다.
스키마(M1~M3)를 앞당기지 않기 위해 실제 `PublicPost`·`PublicComment` 타입으로 타이핑한 **mock 픽스처**로
홈·카테고리·상세·글쓰기·마이·로그인 화면을 구성해 구조를 눈으로 확인할 수 있게 했다.

## 구현 내용

- **모노레포**: pnpm workspace, `save-exact` 고정, `tsconfig.base.json`(strict + `noUncheckedIndexedAccess`),
  ESLint 10 flat config(타입 인식 + `no-explicit-any: error`), Prettier
- **Docker**: Postgres 17(TZ=UTC, healthcheck) + Mailpit. 호스트 5432 충돌로 **5433**에 노출
- **packages/shared**: MBTI 16종, 카테고리 시드, 신고 사유, 위기 키워드 + `detectCrisisKeyword`,
  프로필 enum·라벨, 길이 제한, `PublicAuthor`/`PublicPost`/`PublicComment`/`CursorPage`, `ErrorCode` 38종, 커서 스키마
- **apps/api**: Zod env config(`.env` 명시 로드), Prisma 7 + pg adapter, `app.ts`/`server.ts` 분리,
  `GET /api/health`(DB ping 포함), `{error:{code,message}}` 핸들러, 전역 `Cache-Control: private, no-store`,
  `EmailSender`(mock·smtp) / `RateLimiter`(memory), 시드 진입점
- **apps/web**: Next 16 rewrites, DESIGN 토큰 → Tailwind v4 `@theme` → shadcn 변수 연결, Pretendard self-host,
  `AppShell`(모바일 하단 탭 / ≥1024px 사이드바), `PostCard`·`AuthorLabel`·`MbtiBadge`·`CountRow`·`CareBox`·`EmptyState`,
  TanStack Query provider, api-client
- **스크린샷**: Playwright 2뷰포트 + **가로 스크롤 자동 단정** + 콘솔 에러 수집

### 보고 이후 해소한 것 (같은 마일스톤에서 처리)

사용자 결정에 따라 M0 안에서 문서·코드를 함께 정리했다.

- **D22 `글쓴이` 라벨 확정** — 글·댓글의 익명 여부와 무관하게 항상 `글쓴이`로 표시한다.
  닉네임 글 + 익명 댓글이면 작성자가 드러나지만 의도된 동작이며, 이 경우에도 `nickname`·`id`는
  응답에 담기지 않는다. 라벨 문자열은 `AUTHOR_LABEL` 상수로 단일화해 serializer(M3)와 화면이
  어긋나지 않게 했다. PRD 4장·API.md·ARCHITECTURE.md 반영.
- **D23 `CommentLike` 모델 추가** — `SCHEMA.md`에 `CommentLike`(복합 PK로 중복 공감 차단),
  `User.commentLikes`·`Comment.likes` 관계를 넣고 `API.md`에 `POST/DELETE /comments/:id/like`를 정의했다.
  상세 화면에도 댓글 공감 버튼을 붙였다.
- `Comment.editedAt` 추가, `@([parentId])` 추가
- `AgeRange`에 `TEEN_MID`(14~16세) 추가 — 가입 하한(D6)을 담는 구간
- `EmailVerification.purpose`를 `VerificationPurpose` enum으로 변경
- PRD 3장 반응 항목에 댓글 공감 반영

### 아직 남은 문서-코드 불일치
- 탈퇴 시 `User.nickname`(non-null `@unique`) 처리 방식 미정 → M6
