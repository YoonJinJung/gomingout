# 고밍아웃 PRD (MVP)

## 1. 한 줄 정의
주변에 털어놓기 어려운 고민을, 원할 때는 익명으로 원할 때는 닉네임으로 나눌 수 있는 고민상담 커뮤니티.

## 2. 대상 사용자
- 만 14세 이상
- 지인에게 고민을 말하기 부담스러운 사람, 비슷한 고민을 가진 사람의 이야기를 듣고 싶은 사람

## 3. MVP 범위

### 포함
| 영역 | 기능 |
|---|---|
| 인증 | 이메일+비밀번호 가입, 이메일 인증 코드, 로그인/로그아웃, 비밀번호 재설정, 만 14세 이상 확인, 약관 동의 |
| 프로필 | 닉네임(필수), MBTI(필수), 연령대·성별·현재 상태·자기소개(선택). 항목별 공개/비공개 설정. 프로필 수정 |
| 게시글 | 작성/조회/수정/삭제, 작성 시 익명 또는 닉네임 선택, 익명 시 MBTI 표시 여부 선택(기본 표시), 텍스트만 |
| 댓글 | 작성/수정/삭제, 게시글과 동일한 익명·MBTI 규칙, 익명 번호(익명1, 익명2…), 글쓴이 표시 |
| 카테고리 | 대분류-소분류 2단계 |
| 반응 | 공감(좋아요), 스크랩 |
| 피드 | 최신순, 인기순, 홈 화면 인기글 섹션 |
| 마이페이지 | 내가 쓴 글·댓글, 스크랩한 글 |
| 안전 | 신고, 누적 시 자동 블라인드, 어드민 신고 처리 페이지, 위기 키워드 감지 시 상담 창구 안내 |
| 계정 | 비밀번호 변경, 회원 탈퇴 |
| 기타 | 이용약관·개인정보처리방침 페이지, PWA(홈 화면 추가) |

### 제외 (향후)
- 쪽지(DM) — 스키마·알림 구조는 확장 가능하게 설계
- 알림(앱 내/웹 푸시)
- 검색
- 이미지 첨부
- 소셜 로그인, 휴대폰 인증

## 4. 익명성 규칙
- 글·댓글마다 `익명` / `닉네임` 선택.
- 익명 표시: `익명 · INFP` (MBTI 표시 선택 시) 또는 `익명`.
- 한 게시글 안에서 같은 사람의 익명 댓글은 같은 번호(익명1, 익명2…)를 유지. 글쓴이가 익명 댓글을 달면 `글쓴이`로 표시.
- 익명 글·댓글의 MBTI는 작성 시점 값을 스냅샷으로 저장(이후 MBTI 변경과 무관).
- 프로필 페이지에는 닉네임으로 쓴 글만 노출. 익명 글은 본인의 마이페이지에서만 보임.
- 작성 후 익명/닉네임 전환 불가.
- 운영(신고 처리)을 위해 DB에는 작성자가 연결되어 있으나, 어드민 외 어떤 경로로도 노출되지 않음.

## 5. 프로필
| 항목 | 필수 | 공개 설정 |
|---|---|---|
| 닉네임 | 필수 | 항상 공개 |
| MBTI | 필수 | 공개/비공개 (익명 글 표시는 글 단위로 별도 선택) |
| 연령대 | 선택 | 공개/비공개 |
| 성별 | 선택 | 공개/비공개 |
| 현재 상태(학생·직장인·취준생 등) | 선택 | 공개/비공개 |
| 자기소개 한 줄 | 선택 | 공개/비공개 |

## 6. 카테고리 (초안, 시드 데이터로 관리)
- 연애: 짝사랑, 연애 중, 이별
- 관계: 가족, 친구, 직장 동료
- 진로: 학업, 취업, 이직
- 직장: 업무, 번아웃
- 마음: 우울, 불안, 자존감
- 외모: 다이어트, 피부·헤어, 건강
- 돈: 생활비, 빚, 재테크
- 일상: 잡담, 기타

## 7. 피드·인기글
- 최신순: `createdAt desc`
- 인기순: 시간 감쇠 점수
  `score = (공감×2 + 댓글×3 + 스크랩×2) / (경과시간(h) + 2)^1.5`
  최근 7일 게시글 대상으로 SQL에서 계산(MVP 규모에서는 캐시·크론 불필요).
- 홈 인기글 섹션: 최근 72시간 인기순 상위 5개.

## 8. 안전 기능
### 신고
- 대상: 게시글, 댓글
- 사유: 욕설·비하, 스팸·광고, 음란물, 개인정보 노출, 자해·자살 조장, 기타(상세 입력)
- 같은 대상 중복 신고 불가
- 서로 다른 사용자 신고 5회 누적 시 자동 블라인드(임계값은 설정값)
- 어드민: 신고 목록 조회, 블라인드 유지/복구/삭제, 사용자 정지

### 위기 키워드 안내
- 키워드 목록은 `packages/shared`에 상수로 관리.
- 글·댓글 작성 시 키워드 감지되면 작성 전 부드러운 안내 모달(작성을 막지 않음).
- 감지된 글에는 서버에서 `crisisFlag=true` 저장. 해당 글 상세 하단에 상담 창구 안내 박스 표시.
- 안내 창구: 자살예방상담전화 109, 정신건강위기상담전화 1577-0199, 청소년상담 1388 (배포 전 최신 번호 재확인)

## 9. 화면 목록
1. 홈 (인기글 섹션 + 최신 글)
2. 카테고리 목록 / 카테고리별 피드 (최신·인기 탭)
3. 게시글 상세 (댓글 포함)
4. 게시글 작성·수정
5. 로그인
6. 회원가입 (이메일 → 인증 코드 → 비밀번호 → 연령 확인·약관 동의 → 프로필 설정)
7. 비밀번호 재설정
8. 마이페이지 (내 글 / 내 댓글 / 스크랩)
9. 타인 프로필
10. 프로필 수정
11. 설정 (비밀번호 변경, 로그아웃, 탈퇴)
12. 어드민 신고 관리
13. 이용약관 / 개인정보처리방침

## 10. 비기능 요구사항
- 모바일 우선 반응형
- PWA: manifest, 아이콘, 오프라인 폴백 페이지
- 로그인·가입·인증코드·글 작성에 rate limit
- 비밀번호 bcrypt 해싱
- HTTPS 전용, 인증 쿠키는 httpOnly·Secure·SameSite=Lax
